# ZubaElektro

Elektrik montaj kasbini o'rgatuvchi ilova (Next.js + Supabase).

## Vercel'ga deploy qilish

1. https://vercel.com ga kirib, GitHub akkauntingiz bilan bog'lang
2. "Add New Project" → shu repository'ni tanlang
3. Environment Variables bo'limiga qo'shing:
   - NEXT_PUBLIC_SUPABASE_URL
   - NEXT_PUBLIC_SUPABASE_ANON_KEY
4. Deploy tugmasini bosing
